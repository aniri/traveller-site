# traveller-site

Live site of **Irina Travels** – https://traveller.aniri.ro/

This repo only holds the generated website. It is published automatically:
the `gh-pages` branch is written by the deploy workflow of the private source repo on every merge to its `main` branch. Don't edit it by hand – changes would be overwritten on the next deploy.

GitHub Pages settings: **Source: Deploy from a branch → `gh-pages` / (root)**, custom domain `traveller.aniri.ro`, HTTPS enforced.
